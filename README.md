# DELLI Detailing Lab — конфигуратор тонировки

Одностраничный лендинг с интерактивным подбором тонировки. Чистые HTML5, CSS3 и Vanilla JS: без сборки, фреймворков и Tailwind.

## Как запустить проект

Сборка и установка зависимостей не нужны: это обычные файлы HTML, CSS и JS.

### 1. Скачать проект
Через Git:
```bash
git clone https://github.com/lunyxfon/delli-tinting-configurator.git
cd delli-tinting-configurator
git checkout claude/delli-detailing-landing-dz1du2
```
Или без Git: на странице репозитория на GitHub выберите ветку `claude/delli-detailing-landing-dz1du2`, нажмите **Code → Download ZIP** и распакуйте архив.

### 2. Открыть в браузере

**Вариант А: проще всего.** Дважды щёлкните по `index.html`, и страница откроется в браузере. Всё работает, кроме шрифта Montserrat, если нет интернета: тогда будет системный шрифт.

**Вариант Б: через локальный сервер (рекомендуется).** Ведёт себя так же, как настоящий сайт. Запустите из папки проекта одну из команд:

| Что установлено | Команда | Адрес |
|---|---|---|
| Python 3 | `python3 -m http.server 8000` (Windows: `python -m http.server 8000`) | http://localhost:8000 |
| Node.js | `npx serve .` | http://localhost:3000 |
| VS Code | Установите расширение **Live Server**, затем ПКМ по `index.html` → **Open with Live Server** | откроется само |

Остановить сервер: `Ctrl + C` в терминале.

### 3. Посмотреть мобильную версию
В Chrome нажмите `F12`, затем `Ctrl + Shift + M` (на Mac `Cmd + Shift + M`) и выберите устройство, например iPhone.

### 4. Выложить в интернет (по желанию)
- **GitHub Pages.** В репозитории откройте **Settings → Pages**, в поле *Source* выберите ветку и папку `/ (root)`, нажмите **Save**. Через 1–2 минуты сайт будет доступен по адресу `https://lunyxfon.github.io/delli-tinting-configurator/`.
- **Netlify / Vercel.** Перетащите папку проекта на https://app.netlify.com/drop, и сайт сразу получит ссылку.
- **Свой хостинг.** Загрузите `index.html`, `style.css`, `script.js` и папку `assets/` в корень сайта.

## Структура
```
index.html               — разметка (header, hero, ракурсы, галерея, панель, CTA)
style.css                — дизайн-токены (CSS-переменные), компоненты, адаптив
script.js                — логика конфигуратора
assets/car-ferrari.jpg       — фото автомобиля (1116×580)
assets/car-ferrari-glass.png — маска стёкол того же размера (лобовое + боковое)
assets/studio.jpg            — фото бокса (блоки «О студии» и «Портфолио»)
```

## Как заменить картинки
Тонировка рисуется двумя слоями, которые лежат друг на друге:
1. **Фото автомобиля** (`car-*.jpg`): обычное фото, кадр 1116×580 или с теми же пропорциями.
2. **Маска стёкол** (`car-*-glass.png`): PNG того же размера, где тёмным закрашены только стёкла, а остальное прозрачно. Чтобы на тонированном стекле остались блики, сделайте маску прозрачнее в местах отражений.

Прозрачность маски = степень затемнения. Пути для каждого ракурса задаются в `script.js`, в объекте `ANGLES`. В галерее и в «Популярных вариантах» замените `src` в `index.html`.

## Разделы страницы
| Раздел | Якорь | Что внутри |
|---|---|---|
| Тонировка | `#tinting` | Конфигуратор: ползунок, варианты, тип плёнки, ракурсы, «До / После», галерея |
| Услуги | `#services` | 6 карточек с ценой и сроком, кнопка «Записаться» выбирает услугу в форме |
| Портфолио | `#portfolio` | Сетка работ с фильтром по типу услуги |
| О студии | `#about` | Текст, счётчики с анимацией, 4 шага работы |
| Контакты | `#contacts` | Адрес, телефон, часы, мессенджеры, карта, форма записи |

«Главная» в меню прокручивает к началу страницы. Пункт меню текущего раздела подсвечивается при прокрутке.

## Что заменить на свои данные
- **Цены и сроки** в карточках услуг (`index.html`, раздел «Услуги»).
- **Цифры** в «О студии»: атрибуты `data-count` у `.stat__value`.
- **Адрес, телефон, часы, ссылки** на Telegram и Instagram: в шапке, «Контактах» и футере.
- **Карта:** замените блок `.map` на iframe из [конструктора Яндекс.Карт](https://yandex.ru/map-constructor/) или Google Maps.
- **Фото работ** в «Портфолио»: `src` и подписи у `.work`. Кадрирование задаётся `--pos` (точка фокуса) и `--zoom` (увеличение) в `style` у `.work__media`.

## Отправка заявок
Форма проверяет имя, телефон (маска `+7 (999) 999-99-99`) и согласие. Пока заявка только выводится в консоль браузера и показывается уведомление. Чтобы заявки приходили вам, замените блок с комментарием «Здесь подключается отправка» в `script.js` на `fetch` к вашему обработчику: Telegram-бот, Formspree, почтовый скрипт на хостинге и т.п.

## Интерактив
- Ползунок с шагами 5 / 20 / 33 / 50 / 70 / 95 %: значение в бейдже обновляется сразу, подписи шкалы кликабельны.
- «Популярные варианты» двигают ползунок и подсвечивают карточку.
- Тип плёнки: «Керамическая» или «Карбоновая» (меняется оттенок стёкол).
- «Применить плёнку» переносит настройки на авто. Пока изменения не применены, кнопка пульсирует.
- «Сбросить» возвращает 20 % и «Керамическую».
- Ракурс: активная кнопка + смена изображения. «До / После» делит авто пополам.
- Карточки галереи сразу применяют вариант.
- «Записаться на тонировку» переносит выбранную плёнку и процент в комментарий формы.
- Адаптив: ≤1100px — бургер-меню и одна колонка, ≤760px — мобильная раскладка.
