# DELLI Detailing Lab — конфигуратор тонировки

Одностраничный лендинг с интерактивным подбором тонировки. Чистые HTML5, CSS3 и Vanilla JS: без сборки, фреймворков и Tailwind.

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер:
```bash
npx serve .        # или: python3 -m http.server
```

## Структура
```
index.html               — разметка (header, hero, ракурсы, галерея, панель, CTA)
style.css                — дизайн-токены (CSS-переменные), компоненты, адаптив
script.js                — логика конфигуратора
assets/car-ferrari.jpg       — фото автомобиля (1116×580)
assets/car-ferrari-glass.png — маска стёкол того же размера (лобовое + боковое)
```

## Как заменить картинки
Тонировка рисуется двумя слоями, которые лежат друг на друге:
1. **Фото автомобиля** (`car-*.jpg`): обычное фото, кадр 1116×580 или с теми же пропорциями.
2. **Маска стёкол** (`car-*-glass.png`): PNG того же размера, где тёмным закрашены только стёкла, а остальное прозрачно. Чтобы на тонированном стекле остались блики, сделайте маску прозрачнее в местах отражений.

Прозрачность маски = степень затемнения. Пути для каждого ракурса задаются в `script.js`, в объекте `ANGLES`. В галерее и в «Популярных вариантах» замените `src` в `index.html`.

## Интерактив
- Ползунок с шагами 5 / 20 / 33 / 50 / 70 / 95 %: значение в бейдже обновляется сразу, подписи шкалы кликабельны.
- «Популярные варианты» двигают ползунок и подсвечивают карточку.
- Тип плёнки: «Керамическая» или «Карбоновая» (меняется оттенок стёкол).
- «Применить плёнку» переносит настройки на авто. Пока изменения не применены, кнопка пульсирует.
- «Сбросить» возвращает 20 % и «Керамическую».
- Ракурс: активная кнопка + смена изображения. «До / После» делит авто пополам.
- Карточки галереи сразу применяют вариант.
- Адаптив: ≤1100px — бургер-меню и одна колонка, ≤760px — мобильная раскладка.
